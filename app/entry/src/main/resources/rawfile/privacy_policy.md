# 天关隐私政策

- 应用名称：天关
- 应用包名：cn.alfadb.tianguan
- 开发者：天关开源项目（独立社区项目）
- 联系方式：support@alfadb.cn
- 生效日期：2026-10-26
- 最近更新：2026-10-26

天关是一款运行在 HarmonyOS 上的远程桌面客户端，支持 VNC 与 RDP，用于连接您自己指定的远程服务器。本政策说明天关如何处理与您有关的信息。请您在使用前仔细阅读本政策。

## 一、我们是谁

天关由独立社区项目「天关」开发并维护，采用 GPL-3.0-or-later 许可证，源代码托管于 https://github.com/alfadb/tianguan 。

天关不是云服务，不提供中转、托管或账号服务。远程桌面连接由您的设备直接发起到您指定的服务器，不经过开发者或任何中转服务器。

开发者联系方式：support@alfadb.cn。

## 二、我们收集哪些信息

天关不收集、不上传您的任何个人信息，也不收集设备信息、位置信息、使用统计、崩溃日志或广告标识符。

- 应用内没有账号体系，无需注册或登录。
- 应用不访问通讯录、相册、位置、麦克风、摄像头等个人信息。
- 应用不包含统计、广告、推送、社交或第三方分析 SDK。
- 应用不会把您的连接信息、剪贴板内容或远程画面发送给开发者或任何第三方。

## 三、本机存储的数据

天关只在本机应用沙箱内保存运行所必需的数据，这些数据不会上传到开发者或任何第三方：

- 连接配置：连接名称、主机、端口、协议、用户名、域、分组等，保存在应用沙箱内的 connections.json 文件中。
- 密码：仅当您在保存连接时选择「保存密码」，密码才会保存在系统密钥库（Asset / Keystore）中。应用不写入明文密码，也不会以明文形式读取或展示已保存的密码，密码仅用于向您指定的服务器发起连接。
- 证书指纹：首次连接时由您确认的服务器证书或主机密钥指纹（TOFU，首次信任）保存在应用沙箱内的 vnc-pins.json 文件中，用于在后续连接时识别服务器是否发生变化。

卸载应用或在系统设置中清除应用数据，会删除上述本机数据。天关不提供云端备份，开发者也无法恢复这些数据。

## 四、权限说明

天关只在 module.json5 中声明以下权限，未声明或申请任何其他权限：

- ohos.permission.INTERNET（网络访问，系统授权）
  用途：连接您指定的远程桌面服务器（VNC / RDP），收发画面、键盘鼠标与剪贴板数据。
  可否拒绝：该权限在安装时由系统自动授予，不会弹窗询问，也不能在应用内单独关闭。
  拒绝或不可用的后果：无法建立任何远程桌面连接；在系统设置中禁止本应用联网时，应用的核心功能不可用。

- ohos.permission.PREPARE_APP_TERMINATE（退出应用前的准备，系统授权）
  用途：当您退出应用时，系统会先通知应用。天关借此断开所有远程会话、移除系统托盘图标并清理剪贴板状态，避免留下无法关闭的会话或后台连接。
  可否拒绝：该权限在安装时由系统自动授予，不会弹窗询问。
  拒绝或不可用的后果：应用仍可正常使用，但退出时可能无法保证先完成会话清理（例如旧系统版本不支持该权限时）。

- ohos.permission.READ_PASTEBOARD（读取剪贴板，受限权限，用户授权）
  用途：仅用于「本机 → 远端」剪贴板同步。首次打开远程会话时，应用会通过系统弹窗申请该权限。
  可否拒绝：可以拒绝，也可以随时在系统设置中关闭该权限。
  拒绝或不可用的后果：本机复制的内容不会同步到远端；远端复制到本机、远程画面、键盘鼠标等其余功能均不受影响。拒绝后应用不会退出，也不会反复弹窗（每个应用进程最多询问一次）。

在您同意本政策之前，天关不会申请需要您手动授权的权限。READ_PASTEBOARD 只会在您打开远程会话时申请。

## 五、剪贴板说明

- 剪贴板同步仅在远程会话窗口处于前台时进行；应用进入后台或会话不可见时停止读取本机剪贴板。
- 本机 → 远端：只有在您授权 READ_PASTEBOARD 后，应用才读取本机剪贴板中的纯文本，并仅在内存中转发给当前远程会话。应用不把剪贴板内容写入应用文件，也不上传到任何服务器。
- 远端 → 本机：远端复制的纯文本会写入本机系统剪贴板，同样不写入应用文件、不上传。
- 仅处理纯文本，不处理图片、文件或富文本。单次同步的文本上限为 1 MiB，超出部分会被截断。
- 应用不会在后台读取剪贴板，也不会把剪贴板内容用于广告、用户画像或与远程桌面无关的用途。

## 六、数据共享、转让与公开披露

天关不收集个人信息，因此不向任何第三方共享、转让或公开披露您的个人信息。

远程桌面连接由您的设备直接连接您指定的服务器。该服务器的运营者可能是您本人或第三方，其对数据的处理行为适用该运营者自己的隐私政策，不属于天关控制范围。

## 七、第三方 SDK

天关不集成任何第三方统计、广告、推送、社交或分析 SDK。

应用使用的开源组件（例如 TigerVNC、FreeRDP、libc++ 等）仅在您的设备本地运行，不收集或上传数据。相关许可证与版权声明见应用内「关于」面板以及仓库中的 docs/licensing.md。

## 八、未成年人

天关是通用的远程桌面工具，不面向未成年人单独设计，也不收集任何个人信息。未成年人应在监护人的指导下使用本应用。

## 九、您的权利

由于天关不收集、不上传您的个人信息，开发者处没有可供查询、更正、删除或导出的个人信息。您可以随时在本机管理自己的数据：

- 编辑或删除连接配置；
- 在系统设置中清除应用数据，或卸载应用，以删除本机保存的全部数据；
- 在系统设置中关闭剪贴板读取权限，以停用「本机 → 远端」剪贴板同步；
- 通过卸载应用撤回同意并清除本机数据，下次启动时会重新显示隐私政策同意弹窗。

## 十、政策更新

我们可能因功能变化或法律法规要求更新本政策。更新后的政策会在应用内「关于 → 隐私政策」中展示，并更新文首的最近更新日期与生效日期。

如果更新涉及新的个人信息处理，我们会在应用内以显著方式提示，并在必要时重新征得您的同意。请您在使用前阅读最新版本。
