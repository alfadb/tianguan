## 2. 详细介绍（300–600 字）

天关（Tianguan）是一款面向 HarmonyOS 的原生远程桌面客户端，用 VNC 或 RDP 协议直连你自己的远程主机。它不做中转、不接入任何云服务、不需要注册账号：你在 Windows、Linux 或 macOS 上开好远程服务端（例如 Windows 远程桌面、TigerVNC、macOS 屏幕共享），把地址、端口与账号填进天关即可连接。

同一台设备可以同时打开多个远程会话，每个会话是独立窗口，互不影响；在鸿蒙电脑上还能分别拖到副屏。RDP 会话启用了 GFX 图形管线与 H.264 解码，播放视频、滚动长页面时更跟手；远端声音通过音频通道在本机播放；文本剪贴板双向自动同步，复制粘贴不用来回切换。

安全方面，首次连接会让你核对服务端指纹（VNC 的 RA2 指纹、RDP 的证书 SHA-256），确认后固定下来；之后指纹一旦变化会直接拒绝连接，避免被冒名顶替的服务器截获会话。

界面按窗口宽度自适应：鸿蒙电脑上是「分组栏 + 连接列表」的宽屏双栏，手机上是分组标签加卡片列表。手机端远程画面支持双指缩放与拖动，长按约半秒等于鼠标右键，可以在远端弹出菜单粘贴；在电脑上键盘按键直接透传到远端，中文由远端输入法上屏。

天关以 GPL-3.0-or-later 开源，源码与问题反馈：https://github.com/alfadb/tianguan 。本项目是独立社区项目，与华为没有隶属或合作关系。

**适用范围（请先阅读）**：本应用不提供服务器、不提供演示账号或试用主机，**需要你自备 VNC 或 RDP 服务器/远程主机**（局域网可达，或已做端口映射/VPN 的公网主机）。没有可连接的远程主机时，应用只能管理连接条目，无法体验远程桌面功能。

「天关」之名取自《晋书·卷十一·天文志上》：「天关一星，在五车南，亦曰天门，日月之所行也，主边事，主关闭。」古人以此星为天门、关隘，本应用取其「进出之门户」的意象，作为你连接远程主机的入口；与同名卫星等其它领域的事物无关，本项目是独立社区项目，与华为没有隶属或合作关系。

## 3. 使用须知（商店详情页与首启引导可复用）

1. **需要自备远程主机**：本应用只是客户端，不提供服务器与演示环境。请先在目标电脑上开启 VNC 或 RDP 服务，并确认端口可达（VNC 默认 5901，RDP 默认 3389）。
2. **首次连接必须核对指纹**：第一次连某台服务器时会显示服务端指纹，请与服务器端核对后再点「确认并信任」；指纹变化会被拒绝连接，这是防中间人的设计，不是故障。
3. **剪贴板权限可以拒绝**：首次打开会话时系统会询问是否允许读取剪贴板，用于「本机复制 → 远端粘贴」。拒绝后远程画面与键鼠操作不受影响，只是不再自动同步本机剪贴板。
4. **手机上长按等于右键**：手机端没有物理鼠标时，长按画面约半秒即在远端触发右键，可用来弹出右键菜单并粘贴；双指捏合缩放、双指拖动平移画面。
5. **网络与性能**：连接走你指定的地址直连，不经过我们的服务器；跨公网使用时画质与延迟取决于双方带宽，可在会话中自行缩放观察细节。

## 5. 分类与标签建议

**AGC 一级分类：应用**（不是游戏）。

**二级 / 三级分类**：AGC 的分类树里没有「远程桌面」这个专门类目，且上架时「应用分类标签」只允许选择一个子类、设置后不能自行修改（可参考 [开发者论坛的相关反馈](https://developer.huawei.com/consumer/cn/forum/topic/0201217608073241671)）。按契合度排序给 3 个候选：

| 候选 | 理由 | 风险 |
| --- | --- | --- |
| **商务办公**（推荐） | 远程桌面最典型的使用场景是远程办公、服务器运维、异地访问公司电脑；2in1 用户群体与办公类目高度重合，审核时也最容易解释产品定位。 | 类目竞争大，曝光依赖关键词，需要标签补齐「远程桌面」。 |
| **工具**（次选，最稳） | VNC/RDP 客户端本质是连接工具，归类争议最小，几乎不会被以「类目不符」驳回。 | 工具类目下细分不明显，用户主动检索时更依赖搜索词。 |
| **效率**（备选） | 多会话、剪贴板同步、双指缩放等卖点偏效率向；适合突出「一台设备管多台机器」。 | 与「效率」类目里的笔记、待办类应用混排，定位不够直观。 |

落地建议：二级选「商务办公」，若审核反馈类目不符再改「工具」；申请时在「应用描述/备注」里写明「自备 VNC/RDP 服务器的远程桌面客户端，非 VPN、非代理、无内置服务器」。

**标签（5–8 个）**：`远程桌面`、`VNC`、`RDP`、`远程办公`、`多会话`、`开源`、`服务器运维`、`HarmonyOS PC`

**补充**：首发**只覆盖 PC/2in1**（包内 `deviceTypes` 仍为 `['phone', 'tablet', '2in1']`，AGC 只勾 PC/2in1），商店详情页只需 5 张 PC 截图，建议同时在「平板/PC 应用」专区申请推荐位；手机/平板详情页素材等以后加设备时再补，本目录的 `phone-*.png` 暂作参考。

## 6. 隐私与权限说明（供审核填写）

应用为纯客户端，不收集、不上传任何用户数据，不含广告与统计 SDK，不需要账号；远程连接由用户设备直连用户指定的服务器，不经过任何中转服务器。

| 权限 | 类型 | 用途（一句话） |
| --- | --- | --- |
| `ohos.permission.INTERNET` | normal / system_grant | 与用户指定的 VNC / RDP 主机建立 TCP/TLS 连接，传输画面、键鼠事件与音频。 |
| `ohos.permission.PREPARE_APP_TERMINATE` | normal / system_grant | 用户从系统托盘退出时，先断开所有远程会话并移除托盘图标，避免残留连接或后台占用。 |
| `ohos.permission.READ_PASTEBOARD` | restricted（system_basic）/ user_grant，需 ACL | 仅在远程会话打开且用户授权后读取本机剪贴板文本，用于「本机复制 → 远端粘贴」；拒绝授权不影响远程画面与操作。 |

隐私政策地址（AGC 填写用）：https://tianguan.alfadb.cn/privacy-policy.html
应用内入口：主界面「关于」→「隐私政策 / 查看全文」；首启弹窗要求先同意隐私政策。
